4. REAL EMAIL DISPATCH (SENDING LIVE OTPS TO INBOXES)
--------------------------------------------------------------------------------
By default, BorrowHub logs the OTP code directly to the server terminal and
auto-fills it into the web form for instant testing.

To send real OTP emails directly to student Gmail / SVNIT inboxes:
1. Open backend/.env
2. Configure your SMTP provider (Gmail, Outlook, or SVNIT SMTP):
     SMTP_HOST=smtp.gmail.com
     SMTP_PORT=587
     SMTP_USER=your_email@gmail.com
     SMTP_PASSWORD=your_16_digit_app_password
     SMTP_FROM_EMAIL=your_email@gmail.com
     SMTP_FROM_NAME="BorrowHub SVNIT"
     SMTP_TLS=True

How to get a Gmail App Password:
  - Visit: https://myaccount.google.com/security
  - Enable "2-Step Verification" (if not already enabled)
  - Search for "App Passwords" -> Type name "BorrowHub" -> Click Generate.
  - Paste the 16-character password into SMTP_PASSWORD.
